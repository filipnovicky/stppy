**All functionality from these notebooks has been extracted, refactored, and implemented in the main `stppy` package.**

These notebooks are kept for historical reference only and are **no longer maintained**.

2. **avalanche_detection.ipynb** - Threshold-based and correlation-based detection

4. **merge_blocks.ipynb** - Parallel computation block merging
5. **processing_statistics_newone.ipynb** - Statistical analysis and visualization
6. **spatial_alignment.ipynb** - Spatial and temporal alignment methods
7. **visualization.ipynb** - Topomap visualization
